# 早间科技情报

手机优先的每日科技与 AI 资讯页面，适合早上打开浏览，也可以通过“分享”按钮发送链接。

## 功能

- 聚合 Google News RSS 公开新闻源，覆盖 AI、半导体、互联网与网络安全。
- 页面打开时自动刷新，可手动重新加载，按主题筛选。
- 展示近 7 天内容并缓存上次成功结果，资讯标题链接回原文。
- 含基金研究检查清单；内容用于信息参考，不构成投资建议。

## 在线访问

GitHub Pages 启用后，页面地址为：

https://momentlose.github.io/morning-tech-briefing/

## 数据来源与限制

RSS 经 rss2json 公共转换服务读取；服务限流、网络限制或新闻源变更可能导致更新失败。页面会尝试显示浏览器本地缓存。新闻摘要仅用于快速浏览，请阅读原文并核对日期。

## 发布

推送到 main 分支会通过 GitHub Actions 自动部署 GitHub Pages。
