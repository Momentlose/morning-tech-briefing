# 早间科技情报

手机优先的每日科技与 AI 资讯页面，适合早上打开浏览，也可以通过“分享”按钮发送链接。

## 功能

- 汇总 BBC、Ars Technica、The Verge、OpenAI、NVIDIA 和量子位的公开 RSS 动态。
- GitHub Actions 每天 06:30（北京时间）抓取新闻并发布；也可以在 Actions 页面手动运行。
- 自动生成中文标题并保留原文标题，支持按主题筛选。
- 每篇新闻可展开查看潜在利好、潜在压力和研究关注点，再单独点击“阅读原文”。
- 含基金研究检查清单；内容用于信息参考，不构成投资建议。

## 在线访问

https://momentlose.github.io/morning-tech-briefing/

## 数据来源与限制

页面展示新闻标题，不转载全文。英文标题使用机器翻译，影响分析根据标题与摘要生成，仅作为行业研究线索；不构成个性化投资建议。RSS 更新频率、源站可用性和 GitHub Actions 调度可能影响具体内容与到达时间。请阅读原文并核对发布日期。

## 发布

推送到 main 分支会通过 GitHub Actions 自动更新 Pages。
