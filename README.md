# 早间科技情报

手机优先的每日科技与 AI 资讯页面，适合早上打开浏览，也可以通过“分享”按钮发送链接。

## 功能

- 汇总 36氪、钛媒体、雷峰网、爱范儿、极客公园、IT之家、量子位、虎嗅网，以及知乎热榜、少数派热门文章、虎扑步行街热帖和 B 站热榜。
- 36氪读取 www.36kr.com 官方 RSS，链接直接指向原文；官方源不可用时回退到 Google News 搜索源。
- 知乎热榜和虎扑步行街热帖通过公开榜单接口与版面获取；少数派文章按近期点赞和评论数排序，接口不可用时回退到少数派官方 RSS。
- GitHub Actions 每 6 小时重新抓取，页面显示数据更新时间。各来源独立保留最多 20 条，新闻优先展示最新发布的内容，榜单保留原榜顺序。
- 自动生成英文新闻的中文标题，并保留原文标题；新闻按来源分组，可展开或收起。
- 每条新闻标注资讯员：优先使用原文作者，缺少署名时显示对应媒体的编辑部。
- 来源文件栏默认叠放，点开后展开预览，向下滚动时标题吸顶，再点一次原地收起。长按文件栏标题或新闻，继续按住上下拖动，其他条目会自动让位。松手后对齐并保存到当前浏览器。也可以点「来源排序」或「新闻排序」，聚焦条目后用上下方向键移动，按 Home 置顶。
- 简报列表左侧有吸附轨道，拖动时显示当前来源，松手后吸附到该来源。
- 每条新闻可展开查看潜在利好、潜在压力和研究关注点，点击标题打开报道。
- 收藏保存于当前浏览器的本地存储，不会自动同步到其他设备。
- 社区热榜单独分类；相关分析用于观察讨论趋势，不把热度直接当作公司基本面或投资信号。
- 页面提供基金研究检查清单；内容只作信息参考，不构成投资建议。

## 在线访问

https://momentlose.github.io/morning-tech-briefing/

## 数据来源与限制

每个来源以 15–20 条为目标。抓取数量不足时会补充 30 天内的条目或上次发布的数据，仍不足时按实际条数显示。热榜以入榜时的采集时间判断新鲜度，保留原始发布时间。英文标题使用机器翻译，影响分析根据标题与摘要生成，仅作为行业研究线索，不构成个性化投资建议。请阅读原文并核对发布日期。

官方 RSS 条目不足或不可用时，会尝试对应的补充源。虎嗅网优先采集官网文章，必要时使用 RSS 或 Google News 补充。B 站使用公开排行榜，必要时由综合热门补充。Google News 的链接可能先打开其聚合页。如果媒体未提供可用摘要，页面会提示预览不可用。

## 本地开发

需要 Node.js 22 或更新版本，无需安装第三方依赖。

```powershell
node scripts/fetch-news.mjs
node scripts/serve.mjs
```

打开 http://127.0.0.1:4173 查看页面。抓取脚本需要联网，生成的 `data/` 不提交到仓库。`.local/` 用于临时截图和验证文件，也不提交。

打开 http://127.0.0.1:4173/preview 使用可操作的 iPhone 14 Pro 手机外框预览。模拟屏幕为 393 × 852，扣除状态栏与底部手势区后，网页区域为 393 × 774。手机框会根据预览面板大小等比缩放，框内网页保持手机宽度。此预览使用当前浏览器引擎，不模拟 iOS Safari。

手机端支持顶部固定的分类导航、关键词搜索和整页连续阅读；收藏保存在本机浏览器。搜索范围跟随当前分类，可匹配标题、摘要、来源和作者。

## 发布方式

推送到 main 分支会通过 GitHub Actions 更新 Pages。

工作流先抓取新闻，再运行 `node scripts/build-site.mjs`，发布 `_site/` 下的网页、新闻数据及手机外框预览。线上手机预览入口：https://momentlose.github.io/morning-tech-briefing/preview/ 。
