# 早间科技情报

手机优先的每日科技与 AI 资讯页面，适合早上打开浏览，也可以通过“分享”按钮发送链接。

## 功能

- 汇总 36氪、钛媒体、雷峰网、爱范儿、极客公园、IT之家、量子位，以及知乎热榜、少数派热门文章和虎扑步行街热帖。
- 36氪优先读取官方 RSS；官方源不可用时回退到 Google News 搜索源。
- 知乎热榜和虎扑步行街热帖通过公开榜单接口与版面获取；少数派文章按近期点赞和评论数排序，接口不可用时回退到少数派官方 RSS。
- GitHub Actions 定时生成新闻数据，页面显示数据更新时间。
- 自动生成英文新闻的中文标题，并保留原文标题；新闻按来源分组，可展开或收起。
- 每条新闻可展开查看潜在利好、潜在压力和研究关注点，点击标题打开报道。
- 收藏保存于当前浏览器的本地存储，不会自动同步到其他设备。
- 社区热榜单独分类；相关分析用于观察讨论趋势，不把热度直接当作公司基本面或投资信号。
- 页面提供基金研究检查清单；内容只作信息参考，不构成投资建议。

## 数据来源与限制

页面展示新闻标题和摘要，不转载全文。英文标题使用机器翻译，影响分析根据标题与摘要生成，仅作为行业研究线索，不构成个性化投资建议。RSS 更新频率、源站可用性和 GitHub Actions 调度可能影响具体内容与到达时间。请阅读原文并核对发布日期。

36氪官方 RSS 不可用时会回退到 Google News。此时标题链接可能先打开 Google News 页面；如果媒体未提供可用摘要，页面会明确提示预览不可用。社区榜单使用公开页面接口，结构可能随站点调整；抓取失败时会记录日志，并继续生成其他来源。

## 发布

推送到 main 分支会通过 GitHub Actions 更新 Pages。
